# Discord Fake Deafen

A Vencord or equilot plugin that lets you appear deafened to others while still being able to hear everything!

[![Discord](https://img.shields.io/badge/Discord-Join_Server-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/MCzrs4sTMW)

---

## Features

| Feature | Description |
|---------|-------------|
| **Fake Deafen** | Appear deafened to others while still hearing audio |
| **Context Menu** | Toggle directly from the audio device right-click menu |
| **Custom Keybind** | Set any key combination to quickly toggle fake deafen |
